# Neuromarketing with EEG Signal Analysis and Machine Learning

Code and paper for predicting consumer preference from EEG signals.

**Paper (included as PDF):** A. Ullah, G. Baloch, A. Ahmed, A. B. Buriro, A. Junaid, B. Ahmed and S. Akhtar, "Neuromarketing solutions based on EEG signal analysis using machine learning," *International Journal of Advanced Computer Science and Applications (IJACSA)*, 13(1), 2022.

## Notebooks
| Notebook | What it does |
|---|---|
| `eeg-analysis.ipynb` | Loads and explores the EEG recordings |
| `features-classification.ipynb` | Feature extraction, PCA and classical classifiers (k-NN, decision trees) |
| `coding-04-subjectwise-ann-14-subjects.ipynb` | Subject-wise neural network across 14 subjects |
| `finalized-cnn.ipynb` | Convolutional neural network on the EEG data |

## Stack
Python · NumPy · Pandas · scikit-learn · Keras
